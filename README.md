# 표준분포 학점 계산기

이 프로젝트는 사용자가 입력한 평균, 표준편차, 인원수, 내 점수를 바탕으로 표준분포 상에서 예상 학점, 등수, 상위 백분율, 그리고 학점 구간별 경계값과 상위 백분율을 시각적으로 제공합니다.

## 주요 기능
1. 표준 분포를 기반으로 한 학점 예측
2. 상위 백분율 및 예상 등수 계산
3. 시각적 분포도 표시
   - 정규분포 히스토그램 표시
   - 구간별 상위 백분율 기준 색상 구분
   - 내 점수 위치 표시

## 커스텀 학점 구간 설정
- 학점별 하한선만 입력하면 자동으로 상한선 계산
- 구간별 상위 백분율 자동 계산
- 학점 구간 순서 변경 가능 (화살표 버튼)
- Tab 키를 통한 편리한 데이터 입력
  - Tab: 학점명 → 학점명 → ... → 하한선 → 하한선 순으로 이동
  - Shift + Tab: 역방향 이동

## 데이터 관리
- '값 비우기': 입력 필드 초기화 (설정 유지)
- '설정 초기화': 모든 설정 및 입력값 초기화

## 학점 구간 표시 방식
- X축: 점수
- Y축: 예상 인원수
- 각 구간은 상위 백분율 기준으로 표시됨
  예) A+ (상위 10%), A0 (상위 30%) 등

## 사용 예시
1. 평균(μ), 표준편차(σ), 전체 인원수(N), 내 점수(X) 입력
2. 필요한 경우 학점 구간 설정 커스터마이즈
3. '계산하기' 버튼 클릭
4. 결과 확인
   - 상위 백분율
   - 예상 등수
   - 예상 학점
   - 분포도 시각화
