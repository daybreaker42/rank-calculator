그리고 과목 최대 / 최소 점수를 설정할 수 있게 할건데 - 처음 과목 점수 입력할때 최대 / 최소 / 내 점수 입력하게 할거야.

페이지 구성은 다음과 같음.
1. 메인 페이지 - 검색창이 맨 중앙에 있고, 그 밑으로 최근 투표된 과목들 6개가 인기과목순으로 나열됨.
ㄴ과목 누르면 해당 과목 정보 페이지로 이동. 
2. 검색 페이지 - 검색창 누르면 입력되고 엔터 누르면 검색 페이지로 이동. 검색 페이지에서도 검색 가능.
ㄴ검색시 code / 과목 이름 / 교수명 모두 동시에 검색되고 checkbox / radio 버튼으로 특정 분야 선택은 가능. 근데 기본적으론 통합 검색임.
ㄴ결과 없으면 - 직접 추가하기 가능하게 설정 - 코드, 과목명, 교수 입력 가능하게 - 연도랑 학기는 현재 날짜 기준으로 설정.
3. 과목 정보 페이지 - 해당 과목 시험 (중간, 기말) 점수 공유할 수 있게 - 최대 / 최소 점수는 각 과목별로 저장되고 중간, 기말 따로 설정 가능.
ㄴ들어가면 다른 사람들 점수 보기 전에 먼저 내 점수, 최대 / 최소 점수를 입력해야 함 - 안그러면 점수 못 봄.
ㄴ입력 후 - 다른 사람들 점수 분포 볼 수 있음. 평균, 내 등수도 볼 수 있음.
ㄴ점수 분포는 5점씩 구간 히스토그램으로 표시.
ㄴ내 점수 수정 가능 - 내가 입력한 정보는 기본적으로 표시됨. 그리고 그래프가 메인으로 보임 그 밑에 내가 입력한 점수 보임.
ㄴ그 밑에 댓글 기능 추가. 댓글은 과목별로 저장되고 댓글 작성시 로그인 필요. 
ㄴ이름은 기본적으로 익명 처리됨. 단 익명 유저도 id별로 구분됨. 익명은 1부터 시작되며 1씩 증가함. 과목별 중간 / 기말 게시판 등등 게시판별로 id는 독립적으로 존재함.
ㄴ댓글은 삭제만 가능하게. 수정은 불가. 댓글에 좋아요 정도 누르고 취소 가능.
